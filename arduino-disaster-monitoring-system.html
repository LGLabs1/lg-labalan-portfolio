Project

Arduino-Based Disaster Monitoring System

This project is an Arduino Uno–based disaster monitoring system that uses a water level sensor to track rising water and a fire sensor to detect possible fires. It is designed as a simple early-warning tool for flooding and fire incidents in homes or small communities.

Role Solo developer
Frontend Arduino Uno hardware prototype
Backend Embedded C++ logic, sensors & alerts
Developed Oct-Nov 2024
View Case Study

Overview

This system is built around an Arduino Uno to continuously monitor environmental conditions during potential disasters. A water level sensor measures how high the water has risen, while a fire sensor watches for flames or abnormal heat in the area.

When readings go beyond safe thresholds, the system triggers alarms through simple indicators such as a buzzer, LEDs, or messages on the serial monitor. This gives people an early signal to evacuate or take action before the situation becomes dangerous.

The project focuses on using low-cost components and straightforward code so that it can be replicated or improved for different communities and local scenarios.

Core features

  • Water level monitoring
    • Read continuous data from a water level sensor.
    • Define safe, caution, and danger thresholds inside the Arduino code.
  • Fire detection
    • Use a fire or flame sensor to detect the presence of flames or high heat.
    • Trigger alerts when fire is detected so people can respond quickly.
  • Alert system
    • Activate audible or visual indicators (such as a buzzer or LEDs) when danger levels are reached.
    • Show status or debug messages through the Arduino serial monitor.
  • Low-cost, extendable design
    • Use affordable components such as an Arduino Uno and basic sensors.
    • Keep the code simple so thresholds or additional sensors can be adjusted later.
